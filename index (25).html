Materi Bahasa C

Rangkuman materi yang sesuai dengan soal kuis.

Materi ini sejalan dengan soal-soal kuis. Ketuk judul untuk membuka.

1. Struktur program & input/output

Program C selalu dimulai dari main(). #include <stdio.h> memuat fungsi printf dan scanf. Setiap pernyataan diakhiri ;, dan return 0; berarti program selesai normal.

  • Komentar: // satu baris, /* ... */ banyak baris
  • Specifier: %d int, %f float/double, %c char, %s string, %.2f dua angka desimal, %5d lebar 5
  • \n pindah baris, scanf butuh & (alamat variabel)
#include <stdio.h>

int main() {
    int x;
    scanf("%d", &x);
    printf("Nilai: %d\n", x);
    return 0;
}
2. Variabel & tipe data
  • int bilangan bulat (±4 byte), float/double desimal, char satu karakter (petik tunggal), string pakai petik ganda
  • Nama variabel: tidak boleh diawali angka, tidak boleh pakai -, tidak boleh sama dengan kata kunci (boleh _)
  • const membuat nilai tidak bisa diubah; sizeof memberi ukuran byte (sizeof(char) selalu 1)
  • Casting: (int)3.9 menjadi 3 (desimal dipotong)
  • char adalah angka ASCII: 'A' = 65, jadi 'A'+1 = 'B'
  • unsigned char 255 + 1 berputar ke 0
3. Operator
  • Aritmatika: + - * / %. Perkalian/bagi/sisa dulu, baru tambah/kurang
  • Int / int hasilnya int (7/2 = 3). Pakai 5/2.0 untuk hasil 2.5
  • = memberi nilai, == membandingkan, != tidak sama, >= <=
  • Logika: && DAN, || ATAU, ! TIDAK
  • x += 3 = x = x + 3, tapi x *= 2+3 = x = x * (2+3)
  • x++ pakai nilai lama dulu, ++x menambah dulu. Ternary: kondisi ? a : b
Jebakan: if(x = 5) adalah assignment (selalu benar), bukan perbandingan.
4. Percabangan (if, else, switch)

if jalan kalau syarat benar, else kalau salah. switch tanpa break akan "jatuh" ke case berikutnya.

switch (2) {
  case 1: printf("A");
  case 2: printf("B");  // lanjut ke C
  case 3: printf("C");
}
// output: BC
5. Perulangan (for, while, do-while)
  • for (awal; syarat; langkah) untuk loop berhitung, while cek syarat di awal
  • do-while cek di akhir, jadi minimal jalan sekali
  • break keluar dari loop, continue lompat ke putaran berikutnya
  • Loop bersarang 3 x 2 = 6 kali eksekusi
for (int i = 0; i < 10; i += 3)
    printf("%d ", i);   // 0 3 6 9
6. Array & string
  • Index mulai dari 0: int a[5] punya a[0] sampai a[4]
  • Inisialisasi sebagian, sisanya otomatis 0: int a[5] = {1,2};
  • String = array char berakhir '\0', jadi "abc" berukuran 4 byte
  • <string.h>: strlen (panjang tanpa null), strcpy salin, strcat gabung, strcmp (0 jika sama)
  • <ctype.h>: isdigit dan kawan-kawan. <math.h>: sqrt, pow
  • Array 2D: a[1][2] = baris ke-2, kolom ke-3
  • Akses di luar batas array = undefined behavior
7. Fungsi
  • Fungsi tanpa nilai kembalian bertipe void
  • C memakai pass by value: parameter hanya salinan, variabel asli tidak berubah
  • Variabel lokal hidup di dalam fungsinya; static di dalam fungsi menyimpan nilai antar pemanggilan
  • Rekursi wajib punya base case agar berhenti
int faktorial(int n) {
    if (n <= 1) return 1;       // base case
    return n * faktorial(n - 1);
}
// faktorial(4) = 24
8. Pointer & memori
  • &x alamat x, *p nilai yang ditunjuk p
  • Array yang dikirim ke fungsi menjadi pointer ke elemen pertama; *(p+2) sama dengan p[2]
  • Pointer to pointer: **pp mengikuti dua tingkat sampai nilai
  • const int *p: isi tidak boleh diubah lewat p
  • malloc mengembalikan pointer atau NULL; wajib free agar tidak memory leak
  • Pointer 64-bit berukuran 8 byte
int x = 1;
int *p = &x;
*p = 9;
printf("%d", x);   // 9
9. Operator bit & undefined behavior
  • & AND, | OR, ^ XOR: 6 & 3 = 2, 6 ^ 3 = 5
  • x << 2 sama dengan x dikali 4
  • Makro hanya mengganti teks: KALI(2+3,4) dengan a*b menjadi 2+3*4 = 14
  • static pada fungsi level file membatasi fungsi hanya terlihat di file itu
  • Undefined behavior: x = x++ + ++x, akses array di luar batas, dan sejenisnya
